# Algorithms Playground

This repository is mainly a space to practice mathematics and learn algorithms through code. The goal is to never stop coding while continuously improving my problem-solving skills.

---

## Structure / Estrutura 

- `recursion/` → Problems like Fibonacci, Collatz, and other recursive challenges  
  Problemas como Fibonacci, Collatz e outros problemas recursivos  

- `algorithm-theory/` → Theoretical study and development of algorithmic thinking  
  Estudo teórico e desenvolvimento do raciocínio algorítmico  

- `leetcode/` → Solving problems from LeetCode and other platforms  
  Resolução de problemas do LeetCode e outros sites
